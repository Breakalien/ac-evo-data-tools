Light Color

      
Pick a car's root folder (the one containing materials/ and
        the .actor file). Batch-edits the light-color properties of every
        *_FIXED.material under materials/, and the emitter colors
        declared in the .actor file, all at once - a light-weight alternative to
        opening each one in the Material Editor / Data Editor. Backup files
        (.material.bak / .actor.bak) are always skipped, and a fresh
        .bak is created before any file is first touched.
